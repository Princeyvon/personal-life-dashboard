# Recording workflow audit

The recording control now uses `MediaRecorder` with echo cancellation, noise suppression, automatic gain control, 250 ms data chunks, a five-minute maximum duration, supported MIME negotiation, and explicit stream cleanup. It runs live speech recognition when available, but does not depend on browser speech recognition: if live captions are unavailable, the captured audio is uploaded and sent to the protected server-side Whisper transcription procedure.

The client validates an empty recording and a 16 MB transcription ceiling before upload, uploads through the authenticated `/api/uploads` route, shows a local audio preview, retains a typed/live transcript fallback, and provides distinct loading, processing, unsupported-browser, permission-denied, upload-failure, and transcription-failure messages. Successful voice updates carry the durable S3 object metadata into the existing voice log snapshot without storing audio bytes in the database.
