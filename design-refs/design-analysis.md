# Frontend redesign visual analysis

## Reference system
The redesign uses a pristine light mode with a warm-white canvas, near-black navigation rail, graphite typography, soft ambient shadows, and restrained mint/coral accents. The composition is an airy asymmetric bento rather than a dense card dashboard.

The desktop shell has a detached black rail at the left with a monogram at the top, vertically spaced thin line icons, and a logout affordance near the bottom. The main workspace is a large white surface with generous gutters and clear alignment. Major modules use rounded corners, white-on-white separation, hairline dividers, and soft shadows rather than hard borders.

Typography is a bold modern grotesk: large concise page titles, medium-weight section labels, compact secondary metadata, tabular numeric values, and short action labels. Buttons are black with white text and generous padding; secondary actions are outline/ghost. Progress is communicated with circular rings and thin lines. The main content rhythm alternates between large horizontal rows and a supporting right rail.

## Dashboard
The dashboard reference establishes the primary pattern: greeting banner across the upper left, compact metric tiles in the upper right, then a two-column body. The left column is a “Today” list of large horizontal activity rows, each with a line icon in a pale circular tile, title/subtitle, duration, circular percentage ring, and a black action button. The right column is a “Your life in balance” line chart with a lightweight legend and a small editorial encouragement panel below.

## Fitness
The fitness reference retains the same shell but makes the Live Coach the dominant module. It uses a split hero card with a dark visual/photo panel on the left and exercise controls on the right: current exercise, set count, editable kg/reps steppers, circular rest timer, and a row of set-state markers. Below are two aligned list modules for Workout plan and Recent lift history. The right rail contains a weekly weight chart, goal progress bar, and compact nutrition targets. The page is functional, not decorative: controls are prominent and information hierarchy is immediate.

## Health
Health uses a calmer editorial split: a left sleep diary timeline with large circular milestones and a right disease archive as indexed rows. Coral is reserved for active or time-sensitive health states. The schedule is a concise list below the diary, and the voice log is a prominent top-level input rather than a hidden utility.

## Finance and calendar
Finance uses a ledger-first composition. The top contains three metric tiles, followed by a large recent-transactions table with explicit Add Transaction and Pay / Transfer actions. The right rail carries a compact week strip, today’s agenda, Sleep & Wake summary, and upcoming tasks. RWF amounts are visually dominant and use positive/negative color only as a secondary signal.
